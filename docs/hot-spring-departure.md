# 温泉に行くタイミングを選べるようにする(2026-11-04)

前回 `docs/shop-upgrade-prestige.md` の最後に「決めてほしいこと」として残した、
「金玉を引いた後も遊び続け、好きなときに温泉へ行けるようにする」を実装しました。
参考にしたゲーム(Cookie Clicker のヘブンリーチップス、AdVenture Capitalist のエンジェルなど)では、
「いつリセットするか」を選ぶこと自体が面白さの一つになっています。

## 変わったこと

- **金玉 = 温泉旅行券**: 金玉を引いても、すぐにはエンディングに行きません。「温泉旅行券が当たりました! バス停からいつでも出発できます」と通知し、そのまま遊び続けられます。
- **温泉行きバス停**: ガラポンの南(`(-28, 0, -10)`)に追加。旅行券があるとき [E] で「温泉へ出発する(おみやげ +N個)」。お金と強化がリセットされるので、**もう一度 [E](4秒以内)** で出発します。旅行券がないときは「金玉をひきましょう」と案内するだけです。
- **残っている間も**: ガラポンは回り続け、ロボ・出張買取・放置進行も止まりません。2個目以降の金玉はただの金玉で、旅行券は1枚までです。金玉の天井(確定までのカウント)は旅行券を持った時点で止まります。
- **HUD**: 旅行券を持っている間は「温泉旅行券あり!」と、「あと○円稼ぐと おみやげ+1」を表示します。おみやげの見込み数(この旅で +N)は今までどおりです。
- **最速記録は「金玉までの時間」**: 寄り道しても記録は悪くなりません。エンディングには「金玉までの時間」と「プレイ時間」の両方を表示します。
- セーブデータに `HasTripTicket` と `TripWonSeconds` を追加しました。古いセーブはそのまま読めます(どちらも未設定 = 旅行券なし)。

## シミュレーション(21人の中央値)

模擬プレイヤーは「直近10分のおみやげの増え方が、この周回の平均ペースを下回ったら出発する」(限界価値定理)という方針で動かしています。
`--depart-now` を付けると、これまでどおり金玉を引いた瞬間に出発します。

| | 1周目 | 2周目 | 3周目 | 4周目 |
|---|---|---|---|---|
| すぐ出発(`--depart-now`、以前と同じ) | 1:54 / おみやげ 40 | 1:02 / 18 | 0:48 / 23 | 0:51 / 22 |
| 稼いでから出発(いまの模擬プレイヤー) | 2:06 / 45 | 1:52 / 61 | 1:43 / 54 | 1:42 / 57 |
| うち金玉までの時間 | 1:54 | 0:59 | 0:53 | 0:45 |

- 1周目はまだ稼ぐ速度が上がっている途中なので、寄り道は約11分で終わります。
- 2周目以降は金玉が早く出る一方で、終盤の稼ぎが大きいので、**約1時間残っておみやげを約3倍**にするのが得になります。1時間あたりのおみやげは、すぐ出発で約18個、残ると約33個です。
- 寄り道の上限を10時間にしても(`--max-stay 600`)、出発は金玉から約1時間後でした。いつまでも残るのが正解にはならず、ちょうどよい出発時刻があります。
- すぐ出発する遊び方も選べるので、最速記録を狙う人はこれまでどおり遊べます。

## Unity で確認してほしいこと
1. メニュー `Garapon/Build World` を実行してシーンを作り直す(バス停を追加するため)。PlayMode テスト `GoldDrawWinsTicketAndBusStopLoadsEnding` は、作り直す前だと「Run Garapon/Build World …」で失敗します。
2. 金玉を引いたあと町に残れること、バス停で [E] を2回押すと温泉に出発することを確認する。
3. バス停の位置と大きさが見つけやすいか。

## 決めてほしいこと
- **2周目以降の寄り道が強い**: 上の表のとおり、残って稼ぐほうが1時間あたりのおみやげが約2倍になります。特典をすべて交換し終えるのも早まります(全特典で約420個)。強すぎると感じたら、おみやげの計算式を立方根にする(後半の増え方が鈍る)と、寄り道の得が小さくなります。
