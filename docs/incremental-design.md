# インクリメンタルゲームとしての改善(2026-10-31)

## 調べたこと

| 観点 | 他のインクリメンタルゲームでの定石 | このゲームの状態(変更前) |
|---|---|---|
| コアループ | 稼ぐ → 再投資 → 稼ぐ速度が上がる。放置して戻ると資源が貯まっている | 再投資はできるが、放置で進むものがない |
| 自動化 | 手作業 → 自動化を段階的に解禁するのが中盤の山場 | ロボ・ネットスーパー・潤滑油・ホッパー・モーターは**買えるが効果が未実装** |
| 成長曲線 | コストは指数、生産は線形〜指数。終盤ほど数字が大きくなる気持ちよさ | 抽選は1回転1回で頭打ち |
| オフライン進行 | 上限(8〜24時間)と効率低下つきで「おかえりボーナス」として与える | なし |
| 次の目標の可視化 | 次に何が解禁されるか見せると計画が立てられる | 表示なし |
| 天井(bad luck protection) | 低確率の目玉には救済が定番。最悪ケースの不満を抑える | 金玉 100万分の1 のみ |
| 大きな数の表示 | 単位を付けて短く | `1,234,567,890円` のような桁区切りのみ |

## 変更前の実態(シミュレーション)

`Simulation` で 21 人分のプレイを模擬した結果、変更前のバランスでは**1時間あたり約1,200回**しか抽選できず、金玉(期待値100万回)まで平均で約850時間かかる計算でした。24時間以内にクリアできたのは 21人中1人(運が良かった人)だけです。

## 変更内容

### 自動化アップグレードの実装
| アップグレード | 効果 |
|---|---|
| ごみ拾いロボ | 1レベルごとに毎秒2個分のごみを自動で回収(査定額に加算) |
| 出張買取(旧ネットスーパー) | 5秒ごとにごみと日用品を自動で換金。名前を効果に合わせて変更 |
| 潤滑油 | 回転速度 +25%/レベル、最大4レベル(2倍)。物理挙動が壊れないよう上限を 41倍 → 2倍 に変更 |
| 大型ホッパー | 1回転の抽選数が**レベルごとに2倍**(最大10レベルで1,024回)。玉は1個だけ出て、その中で一番レアな色を表示 |
| 自動モーター | 抽選券がある限りガラポンが自動で回る。必要素材を希少な部品×3 → 道具の部品×5 にして解禁を早めた |

### 新しい仕組み
- **金玉の天井**: 100万回目の抽選は必ず金玉。HUD に「金玉確定まで あと○回」を表示。確率 100万分の1 はそのまま。
- **オフライン進行**: 最後のセーブからの経過時間(最大8時間)の 50% の効率でロボと出張買取が動く。起動時に「おかえりなさい!」メッセージ。
- **高額商品**: お米 10kg(4,000円)、すき焼き肉(2万円)、炊飯器(10万円)、テレビ(50万円)。終盤に食パンを何千個もレジに通さずに済むように。
- **次の目標**: 画面右に「次の目標: ○○ あと○円 / ○○があと○個」を表示。
- **アップグレードの効果表示**: 棚の前で「大型ホッパー 3,000円(1回転の抽選数が2倍)」のように効果を表示。
- **日本式の数字表記**: 1.23万円、45.6億回 など(切り捨てで、買えそうに見えて買えない表示を防ぐ)。
- **演出**: まとめて抽選したときの色別内訳、抽選回数の節目(10, 100, 1,000, 2,000, 5,000, 1万…)で「達成!」メッセージ。
- **その他**: セーブ破損時に起動不能にならず `.broken` に退避して新規開始。モバイル向けにバックグラウンド移行時もセーブ。

### バランス調整
運動靴の初期価格 300→200円、ロボの効果 1→2個/秒、ポイントカードの価格の伸び 1.4→1.3倍 など。数値はすべて `GameData.CreateDefault()` と `Assets/Data/GameData.asset` にあります。

## 変更後のペース(シミュレーション、21人の中央値)

| 到達点 | 時間 |
|---|---|
| 最初のアップグレード | 1分20秒 |
| 抽選10回 | 5分 |
| ごみ拾いロボ | 29分 |
| 大型ホッパー | 37分 |
| 自動モーター | 1時間01分 |
| 抽選10万回 | 1時間34分 |
| クリア | 中央値 3時間00分(最速 1時間07分、最長 3時間07分 = 天井) |

最初の数分で買い物ができ、30分〜1時間で自動化が揃い、あとは放置と再投資で数字が指数的に伸びていく、という定番の曲線になりました。プレイヤーのモデルは概算なので、絶対時間は実機で確認してください。

## Unity での確認が必要なこと
1. **メニュー `Garapon/Build World` を一度実行**してシーンを作り直す(新しい商品棚と HUD の大きさが反映されます)。
2. 潤滑油 4 レベル(2倍速)でガラポンの玉が正常に出るか。
3. 自動モーター + 大型ホッパー最大で、メッセージ表示が騒がしすぎないか。
4. EditMode / PlayMode テスト。
