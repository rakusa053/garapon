# 買い物・強化・周回の作り込み(2026-10-31)

## 他のインクリメンタルゲームの仕組み(調査まとめ)

| 分野 | 代表例 | 仕組み | 狙い |
|---|---|---|---|
| 買い物 | AdVenture Capitalist | 「×1 / ×10 / ×100 / 買えるだけ」の購入数切り替え | 数が大きくなっても操作の手間が増えない |
| 買い物 | Cookie Clicker のゴールデンクッキーなど | 期間限定のチャンス | 「今行くと得」という能動的な理由を作る |
| 強化 | AdVenture Capitalist | 所持数が節目(25・50・100…)に届くと効果が倍増。価格は1回ごとに 1.07〜1.15 倍 | 「あと3つで倍」という近い目標が常に見える |
| 強化 | Cookie Clicker | 条件を満たすと現れる強化。施設Aの数に応じて施設Bが強くなる「シナジー」 | 別々の強化が絡み合い、買う順番に意味が出る |
| 周回 | Cookie Clicker(ヘブンリーチップス)、AdVenture Capitalist(エンジェル) | 累計の稼ぎの平方根・立方根で周回通貨が増え、永続の特典と交換。1個ごとに必要な稼ぎが増える | リセットするほど速くなる。特典を選ぶ楽しみがある |
| 周回 | Antimatter Dimensions ほか | 周回特典で自動化(オートバイヤー)を解放 | 2周目以降の面倒な作業を減らす |

## このゲームに足したもの

### 買い物
- **まとめ買い([Q] で切り替え)**: 「1個ずつ → 10個ずつ → 買えるだけ」。食料品の棚で [E] を押すと、その数をカゴに入れる。「買えるだけ」は所持金と商品券から、カゴの中身を引いた分まで。強化はこれまでどおり1回に1つ。
  - カゴは「商品×個数」で持つようにしたので、食パン10万個でも1行で済む(`ShoppingCart`)。
- **タイムセール**: 1.5〜3分に1回、入荷済みの商品が45秒間だけ特売になる。
  - 強化: 30%引き
  - 食料品: もらえる抽選券が2倍
  - 棚に赤字で「特売!」、画面左に残り秒数を表示。

### 強化
- **節目ボーナス**: 分別袋とごみ拾いロボは、10レベルごとに効果が×1.25(分別袋 Lv40 で約×2.4、ロボ Lv60 で約×3.8)。棚では「Lv12→13 … / Lv20で効果×1.25」と次の節目を見せ、到達すると「節目ボーナスで効果×1.25」と通知する。
- **連携強化(Cookie Clicker のシナジー)**: 条件を満たすと入荷する1回限りの強化。
  - **ごみ収集車**(ロボ Lv10 で入荷): 分別袋1レベルごとにロボ +3%
  - **常連さんの名札**(ポイントカード Lv10 で入荷): スタンプ1個ごとに抽選券 +2%
  - 入荷前は「次の入荷: ??? — ごみ拾いロボをLv10にする」とヒントを出す。
- スタンプを3つ追加(タイムセールで買った・強化の節目に到達・おみやげを交換した)。全23個。

### 周回(おみやげ)
- 温泉から帰ると**おみやげ**(周回通貨)がもらえる。数は「これまでの全周回の累計の稼ぎ ÷ 50万円」の平方根から、もらった数を引いたもの。稼ぐほど増えるが、1個ごとに必要な額は増えていく。
- 画面右に「この旅で +N」と、今クリアしたらもらえる数を常に表示する。
- 町の南に**おみやげ交換所**(6つの窓口)を追加。1周目は「準備中」で、初めて温泉から帰ると開く。

| 特典 | 効果(1レベルごと) | 最大 | 必要なおみやげ |
|---|---|---|---|
| 温泉まんじゅう | 次の周回から 開始時の所持金 +2万円 | Lv5 | 2, 4, 8, 16, 32 |
| マイ分別袋 | 次の周回から 分別袋 Lv+5 でスタート | Lv3 | 4, 8, 16 |
| 旅のお守り | ラッキーごみの出現 +25% | Lv4 | 3, 6, 12, 24 |
| ガラポン名人 | ガラポンの回転速度 +20% | Lv5 | 4, 7, 13, 23, 42 |
| 金のガラポン | 金玉確定までの回数 -10% | Lv5 | 6, 12, 24, 48, 96 |
| ネットスーパー | 出張買取の売上の半分で自動的に抽選券を買う(自動化) | Lv1 | 10 |

- 思い出ボーナス(買取×(1+クリア回数))とスタンプの持ち越しは前回のまま。

## シミュレーション(21人の中央値)

```
dotnet run -c Release --project Simulation            # いまのバランス
dotnet run -c Release --project Simulation -- --no-perks       # おみやげを使わない
dotnet run -c Release --project Simulation -- --no-milestones  # 節目ボーナスなし
dotnet run -c Release --project Simulation -- --no-synergy     # 連携強化なし
dotnet run -c Release --project Simulation -- --no-sale        # タイムセールなし
```

| | 1周目 | 2周目 | 3周目 | 4周目 |
|---|---|---|---|---|
| いまのバランス | 1:54 | 1:02 | 0:48 | 0:51 |
| おみやげを使わない | 1:54 | 1:15 | 1:06 | 1:02 |
| 節目ボーナスなし | 2:58 | 1:49 | 1:30 | 1:24 |
| 連携強化なし | 2:25 | 1:28 | 1:10 | 1:15 |

- おみやげは1周目のクリアで約40個、4周目の開始時に約80個。
- 後半はお金や抽選券より**ガラポンの回転速度**が詰まりどころになる(大型ホッパー最大+自動モーターで1回転1024個)。最初の特典案「抽選券+20%」はほとんど効かなかったため、「回転速度+20%」に差し替えた。
- タイムセールで買う回数は1周目で約20回。ペースはほとんど変わらないので、主に「今スーパーに行く理由」として効いている。
- まとめ買いはシミュレーション上は差が出ない(模擬プレイヤーは元から予算どおり買う)。実際のプレイでは [E] を押す回数が大きく減る。

### 調整したところ
- 節目ボーナスを最初は×1.5(ポイントカードにも適用)にしたら、1周目が1時間7分まで縮んだ。×1.25 にして、分別袋とロボだけに絞った。
- 分別袋の値上がり 1.3→1.36倍、ロボ 1.25→1.3倍、大型ホッパー 2.5→3.0倍。

## 調整用の値(`GameData.CreateDefault()`)
- タイムセール: `SaleIntervalMin/Max`、`SaleSeconds`、`SaleDiscount`、`SaleTicketMultiplier`
- 節目: 各 `UpgradeDef` の `MilestoneEvery`、`MilestoneMultiplier`
- 連携強化の条件: `RequiresId`、`RequiresLevel`
- おみやげ: `SouvenirUnit`(小さいほど多くもらえる)、`Perks` の価格と効果、`AutoShopShare`

変更したら `dotnet run --project Simulation -- --write-asset` で `GameData.asset` を作り直す。
